Round scope: formally designate the three next case studies (A/B/C) as part of
the package's case-study roster in paper_qa_summary.md, with data sources

[DESIGN] Case study A - clinical-covariate trap (BRCA): bundled GSE20685
  (327 tumors, time/event/age/subtype already in colData). Zero new data.
  Angle: naive signature significant univariately, loses significance after
  cox_model adjustment for age + subtype; design_audit flags covariates
  pre-modelling. Source evidence: literature-standard TCGA-BRCA/GSE20685
  adjust-for-stage/age workflow (PLOS ONE 2020 6-gene signature; Sci Rep 2017
  CA20 stage/age confounding).
[DESIGN] Case study C - batch catastrophe: GSE31210 (n=246, GPL570) +
  GSE30219 (n=293, GPL570), identical platform, different studies -> batch-only
  signal; ~50 "prognostic" genes track study/batch; design_audit
  batch_associated_pc + Cramér's V expose it. The GSE30219+GSE37745+GSE50081
  merge is a standard ComBat workflow (AGING 2022 203310/203974; JTD 2025).
[DESIGN] Case study B - cross-histology false transfer (LUAD -> LUSC):
  GSE30219 single cohort with both histologies + survival. Run last (nearest
  overlap with the existing LUAD GSE31210 -> GSE50081 honest negative).
  Held-back alternatives: TCGA-LUAD (~585) / TCGA-LUSC (~504) via UCSC Xena.
  Backups surveyed: GSE68465 (HG-U133A, ~334 curated LUAD), GSE13213 (117),
  GSE157009 (248 LUSC).
[STRATEGY] Sequencing A -> C -> B (A zero-download fastest; C strongest
  design_audit/batch demo; B last to avoid reviewer redundancy with the
  existing honest negative). Experiments run only as dev scripts under
  gitignored validation/cache/; nothing built/committed/pushed until the
  submission verdict; v0.99.0 stays locked.
